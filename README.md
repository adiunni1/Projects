# Projects

A compilation of projects I've done. Each one now lives in its own repository:

- **[stock-price-predictor](https://github.com/adiunni1/stock-price-predictor)** — End-to-end ML pipeline predicting next-day stock direction with XGBoost, walk-forward validation, and a trading-strategy backtest; deployed as a serverless REST API on AWS (S3, Lambda, API Gateway).
- **[appointment-scheduler](https://github.com/adiunni1/appointment-scheduler)** — Python appointment scheduling system that automatically detects scheduling conflicts, built around custom comparison operators (`Appt`, `Agenda` classes).
- **[movie-genre-classifier](https://github.com/adiunni1/movie-genre-classifier)** — K-nearest-neighbors classifier predicting comedy vs. thriller from screenplay word frequencies (85% accuracy).
- **[duck-machine-assembler](https://github.com/adiunni1/duck-machine-assembler)** — Phase 1 of a two-pass assembler for the Duck Machine CPU (CIS 211, University of Oregon), resolving symbolic labels and `JUMP` pseudo-instructions.

A related project, the **CAHOOTS Welfare Check Analyzer** (cloud ML pipeline on AWS, live REST API), is documented alongside the original R-based analysis at [cahoots-welfare-check-analysis](https://github.com/adiunni1/cahoots-welfare-check-analysis).
